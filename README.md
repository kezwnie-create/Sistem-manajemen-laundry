
# SISTEM MANAJEMEN LAUNDRY BERBASIS PYTHON OOP

## Identitas Project
- Mata Kuliah: Pemrograman Berorientasi Objek
- Program Studi: Ilmu Komputer
- Kelas: 3C KOM
- Bahasa Pemrograman: Python

## Deskripsi
Sistem Manajemen Laundry merupakan aplikasi sederhana berbasis Python yang dibuat untuk membantu proses pengelolaan layanan laundry.

Aplikasi ini menerapkan konsep Object-Oriented Programming (OOP).

## Fitur Program
1. Menambahkan data pelanggan.
2. Memilih jenis layanan laundry.
3. Menghitung biaya berdasarkan berat pakaian.
4. Menampilkan daftar pesanan.
5. Mengubah status pesanan.
6. Menampilkan total pembayaran.

## Konsep OOP yang Digunakan
- Class dan Object
- Constructor (__init__)
- Attribute dan Method
- Encapsulation
- Property dan Setter
- Class Method
- Static Method

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Download atau clone repository.
3. Buka terminal pada folder project.
4. Jalankan perintah:

```bash
python main.py
```

## Kesimpulan
Project ini dibuat sebagai penerapan konsep Object-Oriented Programming menggunakan Python dalam sebuah aplikasi pengelolaan laundry sederhana.
